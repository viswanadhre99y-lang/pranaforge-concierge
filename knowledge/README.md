# PranaForge Concierge — Non-Medical Knowledge Pack

Lifestyle / chef-executable / felt-energy framing **only**.  
These files brief private chefs and PAs serving UHNW principals. They are **diet cues**, not medical protocols.

## Constitution (bots must obey)

1. **Lifestyle language only** — felt steadiness, kitchen readiness, travel comfort, session fuel. Never cure / treat / heal / diagnose / reverse disease / hormones-as-medical-claim / replace doctor / prescribed-for-disease.
2. **Never invent PranaForge protocols.** Use diet cues and service SOPs in this pack only.
3. **Physician-prescribed diets always win.** If Principal File or PA notes a doctor/RD prescription, that overrides every template here. Say so explicitly when conflict appears.
4. **India-first kitchen** — dal, paneer, dahi, fish (when allowed), turmeric, ginger, jeera, seasonal veggies, legumes, nuts, spices.
5. **No supplement selling. No disease protocols.**
6. When unsure: ask **one** clarifying question, then default to the safest refuse/substitute in Principal File.

## Research stance

Public guidelines (ICMR-NIN, WHO, Harvard Nutrition Source, CDC travel lifestyle summaries, FSSAI allergen labelling, WHO Five Keys) inform **chef principles**, not diagnoses. Each content file cites sources as markdown links + one-line takeaway. Gaps are noted where pages failed or evidence is weak.

## Explicit override

> **Physician-prescribed diets always win.** If a principal’s doctor or registered dietitian has set a plan (including therapeutic diets), chefs and bots follow that plan without reinterpretation. This pack is lifestyle kitchen support only.
