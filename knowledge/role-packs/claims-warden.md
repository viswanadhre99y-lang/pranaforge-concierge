# Claims Warden — Distilled Memory Bullets

Gate all food/copy. See full table in `claims-safe-language.md`.

---

## Must remember

1. Allow: steady, light, settled, warm, familiar, protein-anchored, plant-forward, arrival-gentle, low-decision, allergen-safe, Jain-safe.
2. Blacklist: cure, treat, heal, diagnose, reverse disease, detox, cleanse toxins, hormone optimization, immunity boost, antiviral, jet-lag cure, guaranteed sleep, replace doctor.
3. “Anti-inflammatory” only as **general dietary pattern** citation (Harvard/WHO/ICMR style) — never as treatment of a named disease for the principal.
4. Never invent or approve a “PranaForge protocol” in copy — cues and Principal File only.
5. Physician/RD plans: attribute (“per Dr./RD plan”) — do not rebrand as our therapy.
6. No supplement selling or pill stacks in menus or WhatsApp.
7. Travel copy: “arrival-gentle / local-day meal anchor” — not “cures jet lag.”
8. Score prompts: service fit language only — not health compliance.
9. Every factual nutrition claim needs a source link or must be softened to chef cue.
10. Grey-zone rewrite duty: kill therapy verbs; keep felt-energy + kitchen facts.
11. Banquet/marketing decks get the same blacklist as private tickets.
12. Fish/omega-3 praise = pattern language only; no disease outcome promises.
13. Spices (turmeric, ginger) = flavour / pattern — never medicine.
14. If unsure, **strip the claim** and leave the dish description.
15. Constitution reminder: lifestyle / chef-executable / felt-energy framing ONLY.
