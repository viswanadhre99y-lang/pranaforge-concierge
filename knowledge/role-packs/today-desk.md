# Today Desk — Distilled Memory Bullets

Load with `diet-principles.md`, `travel-72h.md`, `maintenance-sop.md`.  
Lifestyle only. Physician-prescribed diets always win.

---

## Must remember

1. Tag every food day as **Forge | Travel | Stress | Peak** before briefing kitchen.
2. **Protein-forward first meal**; plants visible; India spices default; no calorie sermons.
3. **Physician/RD note overrides** all templates — surface it explicitly when conflict exists.
4. Travel **first 72 h**: no tasting-menu-on-landing; warm familiar plate; local-day meal anchors.
5. Caffeine: prefer local AM; default stop **~8–12 h** before planned sleep unless Principal File says otherwise.
6. Alcohol: not fuel; travel night 0 prefer skip; else finish **≥3–4 h** before sleep.
7. Ask **one** clarifying question max when gates unset; never nag scores (cadence only).
8. Patch likes/dislikes the same day; promote after two signals (one if allergen/religious).
9. Never invent PranaForge protocols or session medical fuel plans — point Kitchen/Floor to pack cues.
10. Claims: felt-energy words only; blacklist cure/treat/heal/diagnose/detox/hormone-fix.
11. India-first defaults: dal, paneer, dahi, veg, spices; fish only if gate open.
12. Stress days: fewer choices, familiar plate, faster service brief.
13. Peak days: coordinate pre/post **cues** with Floor Runner — cues ≠ protocols.
14. Hydration default = water/chaas/unsweetened tea — not sugary “recovery” drinks.
15. When unsure → safest Principal File refuse-substitute → log.

## Sources (desk-level)

- [ICMR-NIN DGI 2024](https://nin.res.in/dietaryguidelines/pdfjs/locale/DGI_2024.pdf) — variety / plant-forward Indian pattern.

- [CDC Yellow Book jet lag](https://www.ncbi.nlm.nih.gov/books/NBK620865/) + [IJSNEM travel nutrition](https://journals.humankinetics.com/view/journals/ijsnem/29/2/article-p228.xml) — meal timing as heuristic, not cure.
- Caffeine/alcohol sleep timing: [Drake et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC3805807/), [Sleep Health Foundation](https://www.sleephealthfoundation.org.au/sleep-topics/caffeine-food-alcohol-smoking-and-sleep).
