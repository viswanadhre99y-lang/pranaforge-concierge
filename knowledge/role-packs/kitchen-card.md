## Must remember

1. Read Principal File **allergens / Jain / onion-garlic / fish-egg-meat** before mise.
2. **Physician-prescribed diet beats** every template in this pack.
3. Every main needs a **protein anchor** (dal/paneer/dahi/egg/fish/legumes+nuts).
4. India pantry first: dals, paneer, dahi, turmeric, ginger, jeera, seasonal veg, millets/roti/rice.
5. Travel-arrival / Stress defaults: **khichdi (#8), lauki–moong (#10), soup+idli (#12), paneer bowl (#7)** — warm, modest.
6. **No tasting-menu-on-landing**; private kitchen > banquet buffet.
7. Paneer ↔ fish swaps only with gate + principal/PA awareness; never silent.
8. Jain / no-onion-garlic: hing/jeera/tomato paths; **separate utensils** from allium line.
9. WHO Five Keys: clean; separate raw/cooked; cook through; hot >60°C / cold <5°C; ≤2 h room temp; safe water.
10. FSSAI allergen set (gluten cereals, crustaceans, milk, egg, fish, peanut, tree nut, soy, sulphites) — declare & prevent cross-contact; watch sesame for intl guests.
11. Log refusals with substitute; do not re-offer same refuse same day.
12. Ticket language: steady/warm/familiar/protein-anchored — never cure/heal/detox.
13. Peak pre-fuel = light plate 1–2 h before **if File allows** — not an invented protocol.
14. Hold a refuse-safe backup on Stress service.
15. When fetch/vendor fails → simpler dal+sabzi+roti always acceptable.
