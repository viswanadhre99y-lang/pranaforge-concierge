# Claims-Safe Language — Diet & Copy

For **Claims Warden** and any bot writing menus, cards, WhatsApp, or guest-facing notes.  
Lifestyle / chef / felt-energy only.

**Physician-prescribed diets always win** — when citing a clinical diet, attribute it to the clinician (“per Dr. ___ / RD plan”), do not rebrand as PranaForge therapy.

---

## Allowed outcome words (use freely)

| Bucket | Examples |
|--------|----------|
| **Felt energy** | steady, light, clear-headed, settled, comfortable, ready, easeful, buoyant |
| **Kitchen / service** | familiar, warm, soft, composed, private-kitchen, on-time, allergen-safe, Jain-safe |
| **Travel** | arrival-gentle, local-day anchored, modest plate, low-decision |
| **Stress** | simple, reliable, known favourite, one-plate |
| **Peak / session cue** | pre-fuel, post-fuel, light plate, hydrating (water sense only) |
| **Pattern praise** | plant-forward, spice-forward, protein-anchored, India-kitchen native |
| **Satisfaction** | enjoyed, finished, asked for again, preferred |

**Allowed framing phrases**
- “Supports a steady afternoon.”
- “Warm, familiar plate for landing night.”
- “Protein-anchored first meal.”
- “Built from ICMR-NIN / WHO-style healthy-diet patterns (general population guidance).”
- “Per your doctor’s diet instructions” (when true).

---

## Blacklist (never in food/copy)

| Blacklisted | Why |
|-------------|-----|
| cure, cures, cured | medical outcome |
| treat, treatment, treating | medical |
| heal, heals, healing illness | medical |
| diagnose / diagnostic | medical |
| reverse disease / reverse diabetes / reverse inflammation (as claim) | disease claim |
| anti-cancer, prevents cancer | disease claim |
| prescribed for [disease] (as our claim) | usurps clinician |
| replaces your doctor / better than medicine | dangerous |
| hormone optimization / balances hormones / testosterone / cortisol fix | medical-hormone claim |
| detox, detoxify, cleanse toxins | pseudomedical |
| burn fat fast / melt visceral fat | hype / medical-adjacent |
| immunity boost / antiviral plate | medical |
| anti-inflammatory **as treatment for a named disease** | pattern OK; disease treatment NOT |
| protocol (invented PranaForge medical protocol) | inventing protocols |
| supplement stack / must take [pill] | supplement selling |
| jet-lag cure / cures jet lag | medical; use “arrival-gentle meal timing” |
| guaranteed sleep / sedative food | medical |

---

## Grey zone — how to rewrite

| Risky | Safer |
|-------|-------|
| “Anti-inflammatory dinner to treat joint disease” | “Spice- and plant-forward dinner in a general healthy-diet pattern” |
| “This khichdi heals gut” | “Soft, warm, familiar khichdi for an easy evening” |
| “Hormone-balancing breakfast” | “Protein-anchored first meal” |
| “Detox juice after travel” | “Hydrating water + simple fruit; warm plate at dinner” |
| “Our protocol for Peak days” | “Peak-day kitchen cues from the knowledge pack / Principal File” |
| “Clinically proven to reverse…” | Remove — or cite clinician’s own documented plan only |

**Harvard/WHO/ICMR pattern mentions are OK** when framed as *general healthy-diet patterns for the public*, not as treatment of the principal’s condition.  
Cite: [Harvard Anti-Inflammatory Diet review](https://nutritionsource.hsph.harvard.edu/healthy-weight/diet-reviews/anti-inflammatory-diet/), [WHO Healthy diet](https://www.who.int/news-room/fact-sheets/detail/healthy-diet), [ICMR-NIN DGI 2024](https://nin.res.in/dietaryguidelines/pdfjs/locale/DGI_2024.pdf).

---

## Warden checklist (every food string)

1. Any blacklist verb/noun? → rewrite or kill.
2. Invented protocol? → delete; point to Principal File + pack cues.
3. Disease name + food as therapy? → remove therapy claim.
4. Supplement sell? → remove.
5. Physician diet present? → attribute; don’t overwrite.
6. Felt-energy word present? → good.
7. Source needed for factual nutrition claim? → add link or soften to chef cue.
